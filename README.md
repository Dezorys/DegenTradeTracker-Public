# Degen Trade Tracker (Public)

Public Windows installer and update packages for **Degen Trade Tracker**.

- **Binaries only** — no source code in this repository.
- This is **not** a fork of any private source repo; release assets are published here independently.
- Fresh installs do **not** include a trade journal (clean slate).

## Download

See [Releases](https://github.com/Dezorys/DegenTradeTracker-Public/releases) for `DegenTradeTracker-win-Setup.exe`.

## Updates

Install via Setup once, then use **Settings → Check for updates** inside the app (public feed; no token required).
